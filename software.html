01 / In development

SubCalc

Production calculation, manufacturing analysis and decision support.

A drawing arrives, followed by immediate questions: how long will this take, can it be manufactured, and which machine should handle it?

SubCalc is being developed to make this analysis more structured and repeatable. It supports comparisons between machines and alternative manufacturing approaches.

Your production environment

Users build their own production environment inside the software. This may include their machine park, machine capabilities, tooling information and manufacturing conditions, so calculations and recommendations reflect actual production reality.

SubCalc is intended to support manufacturing decisions using structured information. Manufacturing knowledge remains essential.
