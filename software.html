The Sub software family.

Software built from manufacturing experience, with a practical production perspective. Active projects cover machining estimates, NC programming and production resource management.

01 / Active development

SubCalc

Machining estimates and production decision support.

SubCalc helps turn a part and its machining operations into a structured estimate of machining time, cycle time, total order time, material use and tooling needs. Compare the same job across your own machines using their actual capabilities and surrounding process times.

Features

  • Machining operations for turning, drilling, milling, threading, grooving, parting and engraving.
  • A configurable machine fleet with spindle limits, handling times and simultaneous main/subspindle machining where supported.
  • Material planning for bar stock and individual blanks, plus tool consumption and purchasing requirements.
  • Tool and material libraries, with cutting data and pricing information.
  • Complete, simplified and quick PDF reports, plus CSV and text export.
  • Current source workflow: 2D part profiles, operation selection, SubEdit project exchange (.se), SubGlyph engraving import (.sg) and Swedish, English, German and French interfaces.

Calculated times are estimates based on the supplied data. The program does not simulate a complete CNC program or check collisions. Features in the current source may differ from older packaged releases.

02 / Active development

SubEdit

NC editing, visual toolpaths and program comparison.

SubEdit combines an NC editor with graphical XZ turning and XY toolpath views. It helps you follow the relationship between code and movement, compare program revisions and develop turning profiles.

Features

  • NC editing with undo/redo, search, replace and navigation by line.
  • Two-file comparison with highlighted line and NC-field differences, plus navigation between changes.
  • Linked code and toolpath selection, zoom, pan and filters for rapid and machining movements.
  • Projected toolpath measurements for length, arc radius/diameter and angle.
  • Limited macro-expression evaluation with separate test values for preview.
  • XZ profile sketching with lines, arcs and corner radii, plus NC generation for supported external turning profiles.
  • .se projects containing NC text, sketch geometry, operations and used tools; file exchange with SubCalc.
  • Optional connection to SubManager-format tool, machine and equipment registers, with project-specific machine and accessory selections.

Toolpath preview covers supported NC syntax. It does not provide collision checking or a fully compensated finished-part model. NC generation currently covers external turning profiles; controller and machine compatibility must be checked.

03 / Active development

SubManager

Tools, machines and equipment in organised registers.

SubManager is an optional resource manager for the Sub software family. Maintain tool articles, machine capabilities and machine-linked equipment in one place, with searchable records and controlled file exchange.

Features

  • Searchable, sortable tool lists with combined supplier and machining-use filters.
  • Tool article data, insert geometry, prices, cutting data, material profiles and comments.
  • Machine fleet editing for spindles, turrets, process times, speed limits, chuck types and stock forms.
  • Equipment registers for spindle liners, collets, soft jaw sets and other accessories, linked to one or more machines.
  • JSON import/export for tool libraries and machine fleets, with stable IDs and explicit choices when tool data conflicts.
  • Validated file saving, backups and revision checks to help preserve existing register data.
  • Swedish, English, German and French interfaces.

SubManager is optional: SubCalc and SubEdit can work independently. Register sharing and exchange are file based. Compatibility depends on each client version and supported register format.

04 / Existing project

SubGlyph

Multilingual Metric / Imperial mm / inch

SubGlyph is a graphical NC generator for CNC engraving and marking, with support for FANUC, OKUMA OSP and SIEMENS SINUMERIK, multilingual workflows, metric and imperial units, and interactive 3D preview.
